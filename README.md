## Síntesis General del Curso

En este curso de **Python Essentials 1**, se abordaron los fundamentos esenciales del lenguaje de programación Python estructurados en 4 módulos principales:

* **Módulo 1:** Introducción a Python, sintaxis básica, uso e implementación de la función `print()` y entorno de desarrollo.
* **Módulo 2:** Tipos de datos, variables, operadores aritméticos, sintaxis y entrada/salida de datos con `input()`.
* **Módulo 3:** Control de flujo (condicionales `if`-`elif`-`else`, bucles `while` y `for`), operadores lógicos y manipulación de listas.
* **Módulo 4:** Definición de funciones, alcance de variables (*scoping*), estructuras de datos avanzadas (tuplas y diccionarios) y manejo de excepciones con `try`-`except`.
