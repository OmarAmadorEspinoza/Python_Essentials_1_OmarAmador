## Síntesis General del Curso
En este curso de **Python Essentials 1**, se abordaron los fundamentos esenciales del lenguaje de programación Python a lo largo de 4 módulos principales:
1. **Módulo 1:** Introducción a Python, sintaxis básica, función `print()` y herramientas de desarrollo.
2. **Módulo 2:** Tipos de datos, variables, operadores aritméticos y entrada/salida de datos (`input()`).
3. **Módulo 3:** Control de flujo (condicionales `if-else`, bucles `while` y `for`), operaciones lógicas y manipulación de listas.
4. **Módulo 4:** Definición de funciones, alcance de variables (scoping), tuplas, diccionarios y manejo de excepciones (`try-except`).
